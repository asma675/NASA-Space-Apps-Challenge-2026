WINDOWS FIRST TIME
  1. Extract the complete zip, open its extracted folder in VS Code.
  2. Run: py -m pip install -r backend/requirements.txt
  3. Run: py -m uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8765 --reload
  4. Open: http://127.0.0.1:8765
  5. Hard refresh browser with Ctrl + Shift + R.

PARALLAX BLINDSPOT — WORLD DATA OBSERVATORY EDITION
====================================================

NO NASA KEY REQUIRED TO EXPLORE THE DOWNLOADED HISTORICAL/NRT ZIP DATA

WORLD DATA — NASA FIRMS request #850371 (MODIS C6.1) and #850372 (VIIRS S-NPP C2)
  2025-11-12 to 2026-11-13 (MODIS NRT) / 2026-11-02 (VIIRS NRT)
  20,659,624 raw observations in original two NASA ZIPs
  19,573,939 observations included in the global grid/day comparison:
     Standard archives: type=0 presumed vegetation (other NASA type flags excluded)
     NRT: no type field, explicitly included as provisional/unclassified
  5,708,602 worldwide 10-km projected UTC grid-days in indexed database

ALBERTA CASE STUDY
  May–Oct 2023: 547,021 original source records; 542,775 type=0
  Full-resolution database is preserved in data/blindspot.sqlite3

WINDOWS FIRST-TIME START
  1. Extract the complete ZIP to Downloads; open extracted project root in VS Code.
     If you see only one nested folder, open that folder (where backend/ exists).
  2. py -m pip install -r backend/requirements.txt
  3. py -m uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8765 --reload
  4. Open http://127.0.0.1:8765/
  5. Explore at http://127.0.0.1:8765/explore
  6. API check: http://127.0.0.1:8765/api/global/coverage?region=world

JUDGE DEMO (three minutes)
  Enter observatory -> Explore World June 2026 -> Satellite Blindspot Reveal
  -> Drag MODIS vs VIIRS divider -> select a month / focus area -> mission brief.
  Explain that standard 2026 is global and archived Alberta 2023 is a distinct
  case study; neither establishes a 20+ year global climatology.

OPTIONAL CURRENT NASA LIVE API
  NASA FIRMS API MAP_KEY is only needed to fetch observations not already
  contained in the downloaded ZIPs. Put it in .env; never commit .env.

# 90-second judge demonstration (use real data if available)

**0–15 seconds — Who / problem**

"Imagine you're a provincial wildfire seasonal-readiness analyst. You need to know which months have historically demanded monitoring. But the MODIS and VIIRS satellites don't observe fire in identical ways. A chart of raw hotspots can be misleading."

**15–35 seconds — Challenge fulfilled**

Show the selected region and actual imported FIRMS dates. Click the **Fire Time Travel** calendar: "We align detection records to common projected grid-days, so you can inspect month-by-month patterns. We label our measurement rather than calling it a count of fires."

**35–60 seconds — Wow**

Click **Satellite X-Ray**, toggling MODIS, VIIRS, exclusive. "Notice these are different observations. We let you investigate what each sensor reported, with dates and source products. These differences aren't necessarily missed fires."

**60–80 seconds — Stakeholder outcome**

Show **Fire DNA** and Readiness Brief: "A planner now has a starting point for reviewing seasonal monitoring priorities—and an exportable evidence summary with limitations to take to a team meeting."

**80–90 seconds — Trust**

"We don't invent a predictive fire score. We show our method, provenance and remaining uncertainty. Our next step is overpass-aware calibration and validation against Canadian agency histories."

**IMPORTANT:** If using sample data, explicitly say **"This screen uses synthetic data to show the interface; the import pipeline is configured for real NASA FIRMS records."** Never imply fictional figures are actual fires.

# AI assistance — transparent attribution

Parallax BLINDSPOT was created and developed by Asma Ahmed and Ayaan Ahmed (Parallax Labs) with assistance from ChatGPT (OpenAI) for software scaffolding, Python/JavaScript functions, UI layout and CSS, debugging, automated tests, scientific caveat wording and documentation. The Earth Systems pages (`frontend/earth*.js`, `frontend/earth*.css`, `frontend/{earth,vegetation,air-quality,navigation,forecast,cascades}.html`) and `backend/app/earth_systems.py` contain AI-assisted source code and copy; see `EARTH_SYSTEMS_SOURCES_METHODS.md` for implementation and limitations. Image artifacts in these pages are CSS-derived graphics, NASA GIBS satellite imagery and OSM/Esri maps—do not confuse them with AI-generated satellite images. Original NASA FIRMS observations are real downloaded NASA archive data, and external forecast values are retrieved from their cited upstream providers. No claims of validated fire ignition prediction are made.

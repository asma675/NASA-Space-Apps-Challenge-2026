# Third-party services, prior work and inspirations

- **NASA LANCE FIRMS**: archive hotspot observations from MODIS C6.1 and S-NPP VIIRS C2. NASA imagery/data source credit must be retained in exported analysis and presentations. Dataset requests are documented in `METHODS_AUDIT.md`.
- **Natural Resources Canada CWFIS** and **Government of Alberta**: reference links and optional independent agency data services (agency CSV not included in this ZIP).
- **Leaflet**, **Esri World Imagery**, **Esri reference labels**, **MapTiler**, **Globe.GL**: geographic presentation libraries and provider tiles. Follow their respective attribution, key, and usage requirements.
- **Wildfire Watch Canada — HackCanada 2026**: creator's previous project supplied the Esri-imagery/dark-label map aesthetic and historical fire point interaction inspiration. This is pre-existing project work and should be disclosed if required by hackathon rules: https://github.com/asma675/wildfire-watch-canada-HackCanada-2026
- **Zij**: public reference for the challenge's ambition and the importance of documented calibration, held-out evaluation, and 'no data ≠ zero'. Repository: https://github.com/zij-watch/zij. Zij is Apache-2.0 licensed. **No Zij code or visual assets were copied into this release.** The Investigation Theatre is an original plain-JavaScript/Leaflet implementation, with a different design, data model, and scientific claims.

The project must not be presented as implementing Zij's multi-decade/validated methods. It currently ships one real Alberta 2023 season. See `METHODS_AUDIT.md`.

## Global World Atlas (this edition)
- European Commission Joint Research Centre **Global Wildfire Information System (GWIS)**: an independently hosted *external reference* for current and historical context, not embedded as source records: https://gwis.jrc.ec.europa.eu/applications and https://gwis.jrc.ec.europa.eu/apps/country.profile/downloads . Its downloaded burned-area data are a distinct variable from NASA FIRMS thermal hotspots. No GWIS data are locally imported.
- **EPSG:8857 Equal Earth** is used as the globally consistent projected grid for the core aligned analysis. This is a methodological revision from the previous Canada-only projection, and the earlier grid-day counts must not be reused in the global edition.
- NASA FIRMS World Area API: https://firms.modaps.eosdis.nasa.gov/api/area/ ; supports literal `world`, data source codes such as `VIIRS_SNPP_NRT`, and 1–5 days per request. A private MAP_KEY is mandatory for recent requests.
- Project implementation and document drafting were supported by AI coding/writing assistance; all NASA data rows in real mode were imported from the original official archives, never generated by AI. No third-party hackathon project code was simply copied or disguised.

**November 2026 basemap fix:** CARTO changed its basemap access to require a key. BLINDSPOT now uses OpenStreetMap street tiles (with a tile-only CSS night filter) and Esri World Imagery/reference labels for keyless demo geography. OSM tile requests are viewport-only; attribution stays visible. A MapTiler key remains optional.
